# Store_Sales_Kaggle

##  Contexte

La prévision des ventes est un défi fondamental pour les commerces physiques, en particulier les supermarchés. Une estimation incorrecte peut entraîner :
-  Des **pertes financières** dues aux produits invendus et périssables,
- Des **ruptures de stock** frustrant les clients,
- Une **baisse du chiffre d'affaires**.

Dans cette compétition proposée par **Corporación Favorita**, une grande chaîne de supermarchés équatorienne, l’objectif est de prédire les **ventes unitaires** d’articles dans différents magasins en utilisant des données de séries temporelles.


##  Objectif du projet

Développer un **modèle de machine learning** performant pour prédire la quantité d’unités vendues par article et par magasin, à partir :
- de données historiques,
- des promotions,
- de la date,
- et des identifiants de magasins/articles.



##  Datasets

Données fournies par Kaggle :
- `train.csv` : données d'entraînement (date, magasin, article, ventes, promotions)
- `test.csv` : données à prédire (sans les ventes)
- `stores.csv` : information sur les magasins
- `items.csv` : information sur les articles
- `transactions.csv` : volume des transactions journalières
- `oil.csv` : prix du pétrole brut (facteur macroéconomique)
- `holidays_events.csv` : calendrier des jours fériés et événements
